## Mole Desktop v0.10.0

> 相对 `v0.9.0`，本次发布包含未提交的工作区改动。

### 新增功能
- 支持在 Windows 上运行（Beta）：Windows 版本的侧边栏与设置页会显示 Beta 标识，可用于清理、卸载、分析等主要功能。
- 界面用语根据当前系统自动切换：Windows 显示「回收站」「在资源管理器中显示」，macOS 显示「废纸篓」「在 Finder 中显示」，Linux 显示「在文件管理器中显示」。
- Windows 下自动隐藏 Homebrew 管理入口，避免展示当前系统无法使用的功能。

### 体验优化
- 应用卸载的搜索框在 Windows 下改为「搜索应用或发布者」，不再提示 Bundle ID。
- 卸载详情页只在应用存在安装路径时才显示定位按钮，操作区更清爽。
- 窄窗口或矮窗口下，侧边栏会自动收紧间距，底部入口不再被裁掉。
- 详情页的名称、路径与操作按钮支持自动换行，长路径在窄窗口下也能完整显示。

### 问题修复
- 修复窗口宽度较小时主内容区出现横向滚动、页面内容被截断的问题。
- 修复超长文件名或路径把详情头部布局撑开、挤占右侧容量信息的问题。

### 下载
- `Mole-Desktop-macos-universal.dmg` — macOS（Universal，Apple Silicon + Intel）
- `Mole-Desktop-windows-x86_64.msi` — Windows（x86_64）
- `Mole-Desktop-windows-x86_64-setup.exe` — Windows NSIS 安装器

> macOS 安装包使用固定自签名证书签名（未公证）。首次打开如提示
> “无法验证开发者”，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
> 签名身份跨版本固定，已授权的完全磁盘访问等权限升级后不会重置；
> 如果仍遇到旧授权不生效，可执行
> `tccutil reset SystemPolicyAllFiles com.moledesk.app` 后重新授权。
