## Mole Desktop v0.8.0

> 相对 `v0.7.0`，本次发布包含未提交的工作区改动。

### 新增功能
- 配置管理扩展到 51 款开发工具，并按 AI 编程、编辑器、终端与 Shell、版本控制、开发工具、语言与包管理分类展示，新增 Trae、VS Code、JetBrains 系列、Neovim、Vim、Emacs、Zsh、Fish、tmux、Atuin、Docker、Kubernetes、AWS / Google Cloud / Azure CLI、Terraform、npm / pnpm / Yarn / Bun、Cargo、Go、pip、uv、Maven、Gradle、Conda、Android SDK 等。
- 每条配置位置都会说明具体存了什么，并标注删除风险等级：可自动重建、会丢失配置、禁止删除。
- 受保护的配置位置（例如 Shell 框架和全局 Git 配置）默认禁止勾选，清理时也会自动跳过。
- 配置明细、深度清理明细和项目构建产物明细都支持单条删除；删除内容会移入系统废纸篓，在 macOS 上可在本次会话内一键恢复到原位置。
- 新增启动后自动检查更新：发现新版本时顶部显示提示横幅，侧边栏「设置」出现「新版本」标记，可一键前往更新或稍后提醒。
- 工具状态判断更准确：同时检查命令行工具（包括 Homebrew、Cargo、nvm、fnm、asdf、mise 等安装位置）和桌面应用，区分「CLI 可用」「应用已安装」「未检测到 CLI」「仅残留数据」。

### 体验优化
- 删除单项后列表、数量和占用大小立即更新，无需等待重新扫描完成。
- 配置清理完成即返回结果，剩余目录统计转到后台继续，按钮不再长时间等待。
- 明细列表新增悬停操作按钮、删除后的划线状态与恢复按钮，操作路径更清晰。
- 配置页新增风险分级图例，确认弹窗中也会标注每条位置的删除风险。
- 屏蔽了 Cmd/Ctrl+A 对整个界面的全选，只在输入框中保留全选行为。
- 完善了新版本提示、风险标签、明细操作按钮等界面样式。

### 问题修复
- 修复连续删除或刷新时，较早的扫描结果覆盖最新结果、导致统计数字回跳的问题。
- 修复单文件配置在明细中无法正常展开的问题。
- 修复系统配置目录与 XDG 配置目录指向同一位置时，同一配置被重复统计的问题。

### 其他变更
- 新增发布说明生成流程，发布时可基于提交与工作区改动自动生成中文说明并随 Release 发布。
- 版本号更新至 0.8.0。

### 下载
- `Mole-Desktop-macos-universal.dmg` — macOS（Universal，Apple Silicon + Intel）
- `Mole-Desktop-windows-x86_64.msi` — Windows（x86_64）
- `Mole-Desktop-windows-x86_64-setup.exe` — Windows NSIS 安装器

> macOS 安装包使用固定自签名证书签名（未公证）。首次打开如提示
> “无法验证开发者”，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
> 签名身份跨版本固定，已授权的完全磁盘访问等权限升级后不会重置；
> 如果仍遇到旧授权不生效，可执行
> `tccutil reset SystemPolicyAllFiles com.moledesk.app` 后重新授权。
