## Mole Desktop v0.16.0

> 相对 `v0.15.0`，本次发布包含未提交的工作区改动。

### 新增功能

- 新增「启动项与权限」页面（macOS），集中查看「登录时打开」和「App 后台活动」项目：支持按类型和状态筛选、按名称/Bundle ID/路径搜索、全选当前列表，并自动标记应用已不存在的失效项目；可直接禁用、启用或移除项目，系统级项目会要求管理员授权。
- 新增隐私权限管理：扫描用户级和系统级权限记录，按应用列出相机、麦克风、辅助功能、完全磁盘访问等授权项，并识别应用已卸载或已移入废纸篓的失效记录；支持批量清理失效记录，或重置仍安装应用的授权，重置后应用下次使用相关功能时会重新请求授权。
- 仪表盘新增进程列表入口：点击 CPU、内存、硬盘或网络指标卡片即可打开，按 CPU、内存或网络占用排序，每 2 秒自动刷新，显示各进程的上下行速率，并可结束进程（需二次确认，系统进程和本应用不可结束）。

### 体验优化

- 启动项列表按「登录时打开」和「App 后台活动」分组展示，没有独立启动文件的项目提供跳转到系统设置的入口。
- 隐私权限列表支持按用户级、系统级、废纸篓等条件筛选；未获得完全磁盘访问权限时给出说明，并提供直接打开系统设置的按钮。
- 扫描完成后会自动勾选可安全清理的失效项目，减少手动选择。
- 清理历史新增「启动项」和「隐私权限」记录类型，便于回看此前的操作。
- 打开隐私设置时，在 macOS 13 及以上可直接定位到「登录项与扩展」页面。

### 问题修复

- 修复已卸载应用在「隐私与安全性」中留下无法删除的授权条目的问题：清理时通过系统权限服务重置记录，通常无需管理员密码，个别系统版本仍会要求授权。
- 结束进程时先请求正常退出，超时后再强制结束，降低未保存数据丢失的风险。

### 下载
- `Mole-Desktop-macos-universal.dmg` — macOS（Universal，Apple Silicon + Intel）
- `Mole-Desktop-windows-x86_64.msi` — Windows（x86_64）
- `Mole-Desktop-windows-x86_64-setup.exe` — Windows NSIS 安装器

> macOS 安装包使用固定自签名证书签名（未公证）。首次打开如提示
> “无法验证开发者”，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
> 签名身份跨版本固定，已授权的完全磁盘访问等权限升级后不会重置；
> 如果仍遇到旧授权不生效，可执行
> `tccutil reset SystemPolicyAllFiles com.moledesk.app` 后重新授权。
