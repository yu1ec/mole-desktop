## Mole Desktop v0.15.0

> 相对 `v0.14.0`，本次发布包含未提交的工作区改动。

### 新增功能

- 新增「软件更新」页面，可集中查看 Homebrew、App Store、Sparkle（macOS）以及 winget、Microsoft Store（Windows）安装的软件，并对比当前版本与可用版本。
- 支持批量选择软件进行更新，并提供单个更新入口；更新完成后汇总成功与失败项，可展开查看命令输出。
- macOS 上显示应用的代码签名状态（官方签名、ad-hoc 重签、签名已损坏、无签名），并对签名异常的应用给出风险提示。
- App Store 应用缺少 mas 时，可在页面内一键通过 Homebrew 安装 mas；无法自动更新的应用可直接跳转到 App Store 页面。
- Sparkle 应用支持自动下载更新包并原地替换，下载过程中显示进度与速度；`.pkg` 类型会打开系统安装程序完成安装。
- 软件更新结果会记入历史记录，并新增「软件更新」分类。

### 体验优化

- 更新列表支持按「全部」「可更新」「签名异常」及安装渠道筛选，并可按软件名称、ID 或路径搜索。
- 从其他窗口切回时会自动重新校验更新列表；Homebrew 升级或卸载、应用卸载后，更新列表会自动失效并重新扫描。
- 自动替换应用前会校验新版本安装包与当前应用的签名是否一致，避免安装来源不一致的版本。
- App Store 应用即使未被 mas 列出，也会尝试查询版本信息并提供 App Store 页面入口。

### 下载
- `Mole-Desktop-macos-universal.dmg` — macOS（Universal，Apple Silicon + Intel）
- `Mole-Desktop-windows-x86_64.msi` — Windows（x86_64）
- `Mole-Desktop-windows-x86_64-setup.exe` — Windows NSIS 安装器

> macOS 安装包使用固定自签名证书签名（未公证）。首次打开如提示
> “无法验证开发者”，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
> 签名身份跨版本固定，已授权的完全磁盘访问等权限升级后不会重置；
> 如果仍遇到旧授权不生效，可执行
> `tccutil reset SystemPolicyAllFiles com.moledesk.app` 后重新授权。
