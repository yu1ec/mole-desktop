## Mole Desktop v0.13.0

> 相对 `v0.12.1`，本次发布包含未提交的工作区改动。

### 新增功能

- 新增全局右键菜单。在深度清理、应用卸载、开发者配置、Homebrew、磁盘分析、项目产物、安装包和设置等页面，右键点击文件或目录条目即可使用。
- 右键菜单支持「打开」「在文件管理器中显示」「复制路径」。文件可用默认应用直接打开，目录仅提供在文件管理器中定位。
- 一个条目包含多个路径时（如清理项、卸载残留），可逐个在文件管理器中定位，或一次性复制全部路径。
- 顶部更新提示条现在可以直接下载并安装更新：在提示条内显示下载进度、已下载大小与速度，安装阶段提示「正在安装并重启…」，无需再跳转到设置页。
- 更新失败时，提示条会显示错误原因，并提供「重试更新」和「手动下载」入口；自动安装未完成时也会提示手动完成安装的步骤。

### 体验优化

- 右键菜单会自动避开窗口边缘，并可通过按 Esc、点击空白处、滚动页面或窗口尺寸变化关闭。
- 「在文件管理器中显示」现在会直接定位并选中目标文件（macOS 在 Finder 中选中、Windows 在资源管理器中高亮），而不再只是打开所在目录。
- 设置页中的应用程序位置、本地数据目录和权限目录路径均支持右键操作，相关按钮文案会按平台显示为 Finder 或资源管理器。
- 系统剪贴板不可用时会自动改用兼容方式复制路径。
- 更新进行中会隐藏操作按钮并显示进度，避免重复触发下载。
- 更新提示条仍支持「本次不更新」与稍后提醒，并会记住已跳过的版本。

### 下载
- `Mole-Desktop-macos-universal.dmg` — macOS（Universal，Apple Silicon + Intel）
- `Mole-Desktop-windows-x86_64.msi` — Windows（x86_64）
- `Mole-Desktop-windows-x86_64-setup.exe` — Windows NSIS 安装器

> macOS 安装包使用固定自签名证书签名（未公证）。首次打开如提示
> “无法验证开发者”，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
> 签名身份跨版本固定，已授权的完全磁盘访问等权限升级后不会重置；
> 如果仍遇到旧授权不生效，可执行
> `tccutil reset SystemPolicyAllFiles com.moledesk.app` 后重新授权。
